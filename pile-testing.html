Specify the test before requesting a rate

A PDA test and a static load test are different scopes. Send the project specification and identify the test type, pile section, number of tests, test locations, required loading and reporting requirements.

Where the BQ requests a rate only, the quoted rate does not establish a test quantity. The final testing allowance depends on the agreed number and scope of tests.

Agree the responsibilities and deliverables

  • Testing programme and coordination with the piling sequence.
  • Access, pile preparation and site support requirements.
  • Required test equipment, specialist attendance and reporting.
  • Consultant witnessing, submission and acceptance requirements.

The test provider, scope and reporting arrangements will be identified for the project. No independent laboratory accreditation or automatic consultant acceptance is represented by this page.

Send a testing enquiry

Attach the test specification and relevant drawings, name the site and indicate when testing is required. If testing is part of a wider piling package, send the full BQ so the quotation can distinguish pile supply, installation and testing.

For the wider package, see our piling and foundation services. A website enquiry is a request for review, not a confirmed test booking.
